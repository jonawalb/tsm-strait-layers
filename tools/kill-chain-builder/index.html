How to read it

A kill chain is the sequence a military runs to strike a target: find it, fix its position, track it as it moves, target it by assigning a weapon and clearing the shot, engage, and assess the result. U.S. military shorthand for this is F2T2EA. Each step is done by some node, and the chain is only as fast and as sturdy as the path that connects them.

On the board, sensors sit on the left, command nodes and datalinks in the middle, and shooters on the right. A path runs from one sensor, through any command nodes, to one shooter. The tool checks every path and highlights the fastest one that closes. The six bars in the panel show how far the best path gets.

Three things break chains. Reach: a sensor that cannot see the target, or a weapon that cannot reach it. Time: every report, decision and flight minute lets the target move, and once the target has moved farther than the weapon's seeker can search, the shot misses. Structure: if every path runs through one node, one strike ends the chain. The panel counts independent paths and flags single points of failure; the Strike buttons test them.

Presets show three archetypes: a long-range anti-ship ballistic missile chain of the kind the PLA has built, a short coastal defense chain like Taiwan's, and a many-to-many mesh of the kind JADC2, the U.S. plan to link every sensor to every shooter, aims at. Their structure is the lesson. The numbers are round, notional values chosen for teaching.

Method

  • Detection. Each sensor has a reach on each channel it uses (radar, infrared, emissions, acoustic) against a reference target. Active radar reach scales with the fourth root of the target's signature, from the radar range equation; passive sensing scales with the square root. A sensor sees the target if its best channel reaches the target's distance. Over-the-horizon radar has a skip zone inside 800 km notional.
  • Geometry. Land-based nodes sit on the home coast, the set distance from the target. Aircraft, drones and submarines operate forward, at a distance you set per node. Satellites are treated as always in reach when overhead, and their revisit interval sets how long you wait for a look.
  • Fix and track. A path must start with a sensor precise enough to fix the target (location error 5 km or better). The aim point's error at impact is the sensor's own error plus target speed times the age of the data. For the fixing sensor that age is its report time, every relay and decision on the path, launch preparation and flight time. If any live sensor that updates at least every 5 minutes is linked to the shooter, its track can supply the aim point instead; its age is half its update interval, its report time and relay times, plus launch and flight for weapons without in-flight updates. The path tracks if the best error fits inside the weapon's seeker basket and, for a mobile launcher, the whole sequence fits inside the time it stays located.
  • Target and engage. The first command node with firing authority on the path adds its decision time; datalinks only relay. Strike aircraft and submarines can decide on scene. The weapon must reach the target, and ship-only weapons cannot engage a launcher. Assess needs a live damage-capable sensor that sees the target and is linked to the deciding node or the shooter.
  • Independent paths. The count is the largest set of closing paths that share no node. It is computed as a maximum flow in which every node is split in two with capacity one (Menger's theorem), using only links that lie on some closing path; each route the flow finds is checked, and if one does not close by itself the tool falls back to an exact search over closing paths. A single point of failure is a node whose loss alone leaves no closing path, found by re-running the whole evaluation without it, so it also catches a tracking radar that other paths depend on.
  • What is left out. Deception, decoys, weather, jamming short of destruction, reloads, weapon reliability, defenses and the adversary's own reaction. The model tests the structure and timing of a chain. It does not predict outcomes.
